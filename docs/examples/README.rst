Gallery
=======

Every figure below is a composable visualization built in Python with Marsilea and
Matplotlib: complex annotated heatmaps, oncoprints, UpSet plots, sequence logos,
sequence alignments, genome tracks, arc diagrams and single-cell figures. Each
example ships the full script, so you can download it and swap in your own data.
